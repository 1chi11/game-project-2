# 跳弾_個人製作

C++で制作したゲーム作品「とまれない」

## プログラム担当箇所

「プロジェクト/game/」フォルダ内のプログラム全般を担当しました。

主な担当箇所：
- プレイヤー操作
- 敵キャラクターの処理
- オブジェクトの処理
- アイテムの処理
- 当たり判定
- ゲームシステムの実装

## 開発環境

- C++
- Visual Studio
- AQUA Game Library

## 素材について

画像生成AIやフリー素材を使用しています。

## 使用ライブラリについて

### AQUA Game Library

学校から配布されたAQUA Game Libraryを使用しています。

AQUA Game LibraryはDXLibを利用したゲーム制作向けのライブラリです。

### 使用箇所

ゲーム全体のプログラムで使用しています。

主に以下の処理で使用しています。

- ゲームフレームワークの初期化・更新
- ウィンドウ情報の取得
- デルタタイムの取得
- ゲームオブジェクトの検索
- 画面のクリア

### 備考

AQUA Game Libraryは自作したものではなく、
学校から配布されたライブラリを使用しています。

## 実行方法

「実行ファイル」フォルダ内の `game.exe` を起動してください。
