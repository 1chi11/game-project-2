# 2_とまれない_個人製作
C++で制作したゲーム作品「とまれない」

【使用ライブラリについて】

ライブラリ名：AQUA Game Library

概要： 学校で配布されたAQUA Game Libraryを使用しています。 AQUA Game LibraryはDxLibを利用したゲーム制作向けのライブラリです。

使用箇所： ゲーム全体のプログラムで使用しています。 主にゲームフレームワークの初期化・更新、ウィンドウ情報の取得、 デルタタイムの取得、ゲームオブジェクトの検索、画面のクリアなどに使用しています。

備考： AQUA Game Libraryは自作したものではなく、学校から配布されたライブラリを使用しています。
